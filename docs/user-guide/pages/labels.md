# Page Labels

Use labels such as `meeting-notes`, `planning`, or `budget` to organize and find related pages across spaces.

## Add a label

You need edit access to the page to add or remove labels.

1. Open the page and click the **ⓘ** icon to open the **Details** panel.
2. Under **Labels**, click **Add label**, or **Add** if the page already has labels.
3. Select an existing label, or type a new name and click **Create**.

Label names are lowercase, with spaces replaced by hyphens: `Meeting Notes` becomes `meeting-notes`.

## Find pages by label

Click a label in the **Details** panel to see pages with that label. Use **Search by title** or the space filter to narrow the list. Only pages you have access to are shown.

In [Search](/user-guide/search), choose **Filter > Labels** when searching pages, then select one or more labels. Results include pages with any of the selected labels.

## Remove a label

In the **Details** panel, click the **×** next to the label. This removes it from the current page.
