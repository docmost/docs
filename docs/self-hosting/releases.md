# Releases

Docmost is distributed as a Docker image, with release notes published on GitHub. Check the release notes before upgrading your installation.

- [GitHub Releases](https://github.com/docmost/docmost/releases) — release notes, changes, and upgrade notices.
- [Docker Hub](https://hub.docker.com/r/docmost/docmost) — Docker images and available tags.

To update your installation, follow the [upgrade instructions](/installation#upgrade).
