# Übersetzungen

Docmost ist für globale Teams und Communities konzipiert. Die Plattform ist in über 12 Sprachen verfügbar und damit für Benutzer aus verschiedenen Regionen und Branchen zugänglich.

Zu den unterstützten Sprachen gehören:

🇺🇸 Englisch  
🇨🇳 Chinesisch  
🇫🇷 Französisch  
🇩🇪 Deutsch  
🇮🇹 Italienisch  
🇯🇵 Japanisch  
🇰🇷 Koreanisch  
🇧🇷 Portugiesisch  
🇷🇺 Russisch  
🇪🇸 Spanisch  
🇳🇱 Niederländisch  
🇺🇦 Ukrainisch

Die Spracheinstellungen können von jedem Benutzer auf der Seite "Einstellungen > Einstellungen" verwaltet werden, sodass jede Person die Benutzeroberfläche in ihrer bevorzugten Sprache sieht.

</p>

Übersetzungen werden über die Crowdin-Plattform gepflegt und verbessert. Das bedeutet, dass jeder dabei helfen kann, die Sprachübersetzungen zu verbessern.
So beteiligen Sie sich an der Übersetzungsarbeit:
👉 [Docmost Crowdin-Projekt](https://crowdin.com/project/docmost)
