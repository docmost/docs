# Editor

Docmost bietet einen fortschrittlichen WYSIWYG-Rich-Text-Editor. Der Editor unterstützt eine breite Palette von Inhaltstypen, Formatierungsoptionen und Einbettungen, um Ihnen beim Erstellen umfangreicher Dokumentation zu helfen.

## Slash-Befehle

Geben Sie `/` in einer neuen Zeile ein, um das Menü der Slash-Befehle zu öffnen. Sie können auch tippen, um Befehle nach Namen zu filtern. Die folgenden Befehle sind verfügbar:

### Grundlegend

| Befehl | Beschreibung |
|---------|-------------|
| **Text** | Einfacher Absatztext |
| **To-do-Liste** | Verfolgen Sie Aufgaben mit einer To-do-Liste mit Kontrollkästchen |
| **Überschrift 1** | Große Abschnittsüberschrift |
| **Überschrift 2** | Mittlere Abschnittsüberschrift |
| **Überschrift 3** | Kleine Abschnittsüberschrift |
| **Aufzählungsliste** | Erstellen Sie eine ungeordnete Aufzählungsliste |
| **Nummerierte Liste** | Erstellen Sie eine geordnete nummerierte Liste |
| **Zitat** | Erstellen Sie ein Blockzitat |
| **Code** | Fügen Sie einen Codeblock mit Syntaxhervorhebung ein |
| **Trennlinie** | Fügen Sie eine horizontale Trennlinie ein |

### Medien

| Befehl | Beschreibung |
|---------|-------------|
| **Bild** | Laden Sie ein Bild von Ihrem Gerät hoch |
| **Video** | Laden Sie ein Video von Ihrem Gerät hoch |
| **Dateianhang** | Laden Sie eine beliebige Datei von Ihrem Gerät hoch |

### Struktur

| Befehl | Beschreibung |
|---------|-------------|
| **Tabelle** | Fügen Sie eine Tabelle ein |
| **Umschaltblock** | Fügen Sie einen einklappbaren Block ein |
| **Callout** | Fügen Sie einen Callout-Hinweisblock ein |

### Erweitert

| Befehl             | Beschreibung                                                    |
|---------------------|----------------------------------------------------------------|
| **Inline-Mathematik**     | Fügen Sie eine Inline-Mathematikgleichung ein (KaTeX)                         |
| **Mathematikblock**      | Fügen Sie eine Mathematikgleichung auf Blockebene ein (KaTeX)                     |
| **Mermaid-Diagramm** | Fügen Sie ein Mermaid-Diagramm ein (Flussdiagramme, Sequenzdiagramme usw.) |
| **Draw.io**         | Öffnen Sie den Draw.io-Diagrammeditor                                |
| **Excalidraw**      | Öffnen Sie den Excalidraw-Whiteboard-Editor                          |
| **Datum**            | Fügen Sie ein Datum mit einer Kalenderauswahl ein                           |
| **Unterseiten**        | Listen Sie alle untergeordneten Seiten der aktuellen Seite auf                       |
| **Status**          | Zeigen Sie ein benutzerdefiniertes Status-Badge auf der Seite an.                        | |

### Einbettungen

| Befehl | Beschreibung |
|---------|-------------|
| **Iframe-Einbettung** | Betten Sie Inhalte über eine Iframe-URL ein |
| **Airtable** | Betten Sie eine Airtable-Base ein |
| **Loom** | Betten Sie ein Loom-Video ein |
| **Figma** | Betten Sie Figma-Dateien ein |
| **Typeform** | Betten Sie ein Typeform ein |
| **Miro** | Betten Sie ein Miro-Board ein |
| **YouTube** | Betten Sie ein YouTube-Video ein |
| **Vimeo** | Betten Sie ein Vimeo-Video ein |

| **Google Drive** | Betten Sie Google-Drive-Inhalte ein |

| **Google Docs** | Betten Sie Google Docs ein |

## Formatierungsleiste

Wählen Sie Text aus, um die schwebende Formatierungsleiste anzuzeigen. Die Leiste bietet schnellen Zugriff auf:

- **Ask AI** - Verwenden Sie den AI-Assistenten als Hilfe beim Schreiben
- **Blocktyp** - Konvertieren Sie den Block in einen anderen Typ (Text, Überschrift 1-3, To-do-Liste, Aufzählungsliste, Nummerierte Liste, Blockzitat, Code, Callout, Umschaltblock)
- **Ausrichtung** - Richten Sie Text linksbündig, zentriert, rechtsbündig oder im Blocksatz aus
- **Fett** (`Ctrl/Cmd + B`)
- **Kursiv** (`Ctrl/Cmd + I`)
- **Unterstrichen** (`Ctrl/Cmd + U`)
- **Durchgestrichen**
- **Inline-Code** (`Ctrl/Cmd + E`)
- **Link** - Fügen Sie einen Hyperlink ein oder bearbeiten Sie ihn
- **Textfarbe** - Wählen Sie aus einer Palette von Textfarben
- **Hervorhebungsfarbe** - Wählen Sie aus einer Palette von Hintergrund-Hervorhebungsfarben
- **Kommentar** - Fügen Sie einen Inline-Kommentar zum ausgewählten Text hinzu

## @-Erwähnungen

Geben Sie `@` im Editor ein, um das Erwähnungsmenü zu öffnen. Das Menü zeigt zwei Abschnitte:

- **Benutzer** - Erwähnen Sie Arbeitsbereichsmitglieder namentlich. Erwähnte Benutzer erhalten möglicherweise Benachrichtigungen.
- **Seiten** - Verlinken Sie auf vorhandene Seiten in Ihrem Arbeitsbereich. Tippen Sie, um nach einer bestimmten Seite zu suchen.

## Emoji

Geben Sie `:` gefolgt von einem Schlüsselwort ein, um Emoji zu suchen und einzufügen. Zum Beispiel zeigt `:smile` passende Emoji-Vorschläge an.

## Diagramme

Der Editor unterstützt drei Diagramm-Tools, die Sie über das `/`-Slash-Befehlsmenü einfügen können:

- **Mermaid** - Schreiben Sie textbasierte Diagramme mit Mermaid-Syntax (Flussdiagramme, Sequenzdiagramme, Gantt-Diagramme und mehr).
- **Draw.io (diagrams.net)** - Erstellen Sie visuelle Diagramme mit einem voll ausgestatteten Drag-and-Drop-Editor.
- **Excalidraw** - Erstellen Sie Whiteboard-Diagramme im handgezeichneten Stil.

Weitere Details finden Sie auf der Seite [Diagramme](./diagrams).

## Anker

Sie können Seitenanker in Überschriften kopieren, um schnell auf bestimmte Abschnitte zu verlinken. Bewegen Sie einfach den Mauszeiger über eine Überschrift, um das Ankersymbol anzuzeigen, und klicken Sie dann, um den Link zu kopieren.

## Tabellen

Um eine Tabelle einzufügen, geben Sie `/` ein und wählen Sie **Tabelle**. Eine 3×3-Tabelle wird eingefügt, wobei eine Kopfzeile standardmäßig aktiviert ist.

### Tabellenleiste

Klicken Sie in eine Tabellenzelle, um die Tabellenleiste über der Tabelle anzuzeigen. Die Leiste bietet die folgenden Aktionen:

| Aktion | Beschreibung |
|--------|-------------|
| **Spalte links hinzufügen** | Fügen Sie eine neue Spalte links von der aktuellen Zelle ein |
| **Spalte rechts hinzufügen** | Fügen Sie eine neue Spalte rechts von der aktuellen Zelle ein |
| **Spalte löschen** | Entfernen Sie die aktuelle Spalte |
| **Zeile oberhalb hinzufügen** | Fügen Sie eine neue Zeile oberhalb der aktuellen Zelle ein |
| **Zeile unterhalb hinzufügen** | Fügen Sie eine neue Zeile unterhalb der aktuellen Zelle ein |
| **Zeile löschen** | Entfernen Sie die aktuelle Zeile |
| **Kopfzeile umschalten** | Aktivieren oder deaktivieren Sie den Kopfzeilenstil für die erste Zeile |
| **Kopfspalte umschalten** | Aktivieren oder deaktivieren Sie den Kopfspaltenstil für die erste Spalte |
| **Tabelle löschen** | Entfernen Sie die gesamte Tabelle |

### Tabellenfunktionen

- **Spalten anpassen** — Ziehen Sie die Spaltenränder, um die Spaltenbreiten anzupassen.
- **Zeilen und Spalten neu anordnen** — Ziehen Sie Zeilen oder Spalten, um sie neu anzuordnen.
- **Zellen verbinden** — Wählen Sie mehrere Zellen aus und verbinden Sie sie zu einer.
- **Zellen teilen** — Teilen Sie eine zuvor verbundene Zelle wieder in einzelne Zellen auf.
- **Zellausrichtung** — Richten Sie den Zellinhalt linksbündig, zentriert oder rechtsbündig aus.
- **Zellhintergrundfarbe** — Legen Sie eine Hintergrundfarbe für einzelne Zellen fest.

### Navigation

Verwenden Sie `Tab`, um zur nächsten Zelle zu wechseln, und `Shift + Tab`, um zur vorherigen Zelle zu wechseln.

## Drag-and-Drop

Bewegen Sie den Mauszeiger über einen beliebigen Block, um links einen Ziehgriff anzuzeigen. Klicken und ziehen Sie den Griff, um Blöcke innerhalb der Seite neu anzuordnen.

### Markdown-Kürzel

Der Editor unterstützt während der Eingabe standardmäßige Markdown-Kürzel:

| Eingabe | Ergebnis |
|-------|--------|
| `# ` | Überschrift 1 |
| `## ` | Überschrift 2 |
| `### ` | Überschrift 3 |
| `#### ` | Überschrift 4 |
| `##### ` | Überschrift 5 |
| `###### ` | Überschrift 6 |
| `- ` or `* ` | Aufzählungsliste |
| `1. ` | Nummerierte Liste |
| `[ ] ` | To-do-Listenelement |
| `> ` | Blockzitat |
| `` ``` `` | Codeblock |
| `---` | Trennlinie |
| `**text**` | Fett |
| `*text*` or `_text_` | Kursiv |
| `` `text` `` | Inline-Code |
| `~~text~~` | Durchgestrichen |
| `$$text$$` | Inline-Mathematikgleichung |
| `$$$text$$$` | Mathematikblock |
| `:::` | Callout-Block |

Sie können auch Markdown-Inhalte direkt in den Editor einfügen, und sie werden automatisch in Rich-Text umgewandelt.
