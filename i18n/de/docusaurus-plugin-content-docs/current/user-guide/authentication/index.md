# Authentifizierung
Die Authentifizierung in Docmost gewährleistet eine sichere und effiziente Zugriffsverwaltung und bietet Flexibilität für Benutzer und Administratoren gleichermaßen.

Mit Single Sign-On (SSO), das für Enterprise-Bereitstellungen verfügbar ist, können sich Teams über ihren bestehenden Identitätsanbieter authentifizieren und so ein nahtloses Anmeldeerlebnis genießen.

Zu den Authentifizierungsmethoden in Docmost gehören:
- Authentifizierung per E-Mail und Passwort
- LDAP (enterprise)
- SAML 2.0 (enterprise)
- OpenID Connect (OIDC) (enterprise)
- Microsoft Azure Entra (Active Directory), Okta, OneLogin, Google SSO, Keycloak, Authentik, Authelia, Duo und andere mit SAML 2.0 und OpenID Connect kompatible Anbieter.

Informationen zur automatisierten Benutzer- und Gruppenprovisionierung von Ihrem Identitätsanbieter finden Sie unter [SCIM](./scim.md) (enterprise).
