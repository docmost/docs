# Präferenzen

Jeder Benutzer kann sein Docmost-Erlebnis über die Seite Präferenzen anpassen. Um auf Ihre Präferenzen zuzugreifen, gehen Sie zu **Einstellungen** > **Präferenzen**.

## Design

Wählen Sie Ihr bevorzugtes Farbschema für die Benutzeroberfläche.

- **Hell** — Heller Hintergrund mit dunklem Text.
- **Dunkel** — Dunkler Hintergrund mit hellem Text.
- **Systemeinstellungen** — Folgt automatisch der Design-Einstellung Ihres Betriebssystems.

## Sprache

Wählen Sie Ihre bevorzugte Sprache für die Benutzeroberfläche. Docmost unterstützt mehrere Sprachen. Wählen Sie eine Sprache aus dem Dropdown-Menü, um die Benutzeroberfläche umzustellen.

## Volle Seitenbreite

Aktivieren Sie diese Option, um Seiten auf die volle Breite des Browserfensters zu erweitern. Wenn die Option deaktiviert ist, werden Seiten mit einer zentrierten, schmaleren Inhaltsbreite für bessere Lesbarkeit angezeigt.

Sie können diese Einstellung auch über das Seitenmenü (`…`) mit der Option **Volle Breite** ändern.

## Standard-Bearbeitungsmodus für Seiten

Wählen Sie den Standardmodus beim Öffnen einer Seite:

- **Bearbeiten** — Seiten werden im Bearbeitungsmodus geöffnet, bereit für Änderungen.
- **Lesen** — Seiten werden im schreibgeschützten Modus geöffnet. Dies hilft, versehentliche Änderungen zu vermeiden. Bei Bedarf können Sie über die Seiten-Symbolleiste in den Bearbeitungsmodus wechseln.

## Fixierte Editor-Symbolleiste {#fixed-editor-toolbar}

Aktivieren Sie **Fixierte Editor-Symbolleiste**, um beim Bearbeiten einer Seite Formatierungsoptionen oberhalb des Editors anzuzeigen.

## E-Mail-Benachrichtigungen {#email-notifications}

Wählen Sie unter **E-Mail-Benachrichtigungen**, welche E-Mails Sie erhalten:

| Einstellung | Wann Sie eine E-Mail erhalten |
|-------------|-------------------------------|
| **Seitenaktualisierungen** | Beobachtete Seiten werden aktualisiert, einschließlich Seiten in beobachteten Bereichen. |
| **Seiten-Erwähnungen** | Jemand erwähnt Sie auf einer Seite. |
| **Kommentar-Erwähnungen** | Jemand erwähnt Sie in einem Kommentar. |
| **Neue Kommentare** | Jemand kommentiert eine beobachtete Seite oder antwortet in einer Diskussion, an der Sie teilnehmen. |
| **Erledigte Kommentare** | Jemand erledigt Ihren Kommentar. |

Die Einstellung **Seitenaktualisierungen** steuert E-Mail- und In-App-Benachrichtigungen über Änderungen an beobachteten Seiten.
