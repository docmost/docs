# Seitenbeschriftungen

Verwenden Sie Beschriftungen wie `besprechungsnotizen`, `planung` oder `budget`, um zusammengehörige Seiten über mehrere Bereiche hinweg zu organisieren und zu finden.

## Eine Beschriftung hinzufügen {#add-a-label}

Sie benötigen Bearbeitungsrechte für die Seite, um Beschriftungen hinzuzufügen oder zu entfernen.

1. Öffnen Sie die Seite und klicken Sie auf das Symbol **ⓘ**, um die Seitenleiste **Details** zu öffnen.
2. Klicken Sie unter **Beschriftungen** auf **Beschriftung hinzufügen** oder auf **Hinzufügen**, wenn die Seite bereits Beschriftungen hat.
3. Wählen Sie eine vorhandene Beschriftung oder geben Sie einen neuen Namen ein und klicken Sie auf **Erstellen**.

Namen werden kleingeschrieben und Leerzeichen durch Bindestriche ersetzt: Aus `Meeting Notes` wird `meeting-notes`.

## Seiten anhand einer Beschriftung finden {#find-pages-by-label}

Klicken Sie in der Seitenleiste **Details** auf eine Beschriftung, um Seiten mit dieser Beschriftung anzuzeigen. Grenzen Sie die Liste über **Nach Titel suchen** oder den Bereichsfilter ein. Es werden nur Seiten angezeigt, auf die Sie Zugriff haben.

Wählen Sie in der [Suche](/user-guide/search) beim Suchen nach Seiten **Filter > Beschriftungen** und dann eine oder mehrere Beschriftungen. Die Ergebnisse enthalten Seiten mit mindestens einer der ausgewählten Beschriftungen.

## Eine Beschriftung entfernen {#remove-a-label}

Klicken Sie in der Seitenleiste **Details** auf das **×** neben der Beschriftung. Dadurch wird sie von der aktuellen Seite entfernt.
