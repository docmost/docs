# Präsentationsmodus

Mit dem Präsentationsmodus wird jede Seite zu einer Folienpräsentation, die Sie direkt in Docmost zeigen können.

## Eine Präsentation starten

1. Öffnen Sie die Seite, die Sie präsentieren möchten.
2. Öffnen Sie oben rechts das Seitenmenü (`...`).
3. Klicken Sie auf **Präsentationsmodus**.

Der Seitentitel ist Ihre erste Folie. Für Bases ist der Präsentationsmodus nicht verfügbar.

## Folien erstellen

Docmost teilt Ihre Seite automatisch in Folien auf. Jede Überschrift 1 und jede Trennlinie beginnt eine neue Folie. Um eine Trennlinie einzufügen, geben Sie in einer neuen Zeile `/trennlinie` oder `---` ein.

Wenn eine Folie mehr Inhalt hat, als auf den Bildschirm passt, geht es auf der nächsten Folie weiter. Lange Tabellen und Codeblöcke bekommen eine eigene Folie, in der Sie scrollen können. Leere Zeilen werden übersprungen.

## Zwischen Folien wechseln

- Nutzen Sie die Pfeile unten auf dem Bildschirm oder die Pfeiltasten Ihrer Tastatur.
- Auch die Leertaste und Bild ab wechseln zur nächsten Folie, daher funktionieren auch Präsentationsfernbedienungen. Auf einer langen Folie scrollen sie zuerst nach unten.
- Ein Klick auf eine Folie wechselt die Folie nicht. So können Sie Links anklicken, Umschaltblöcke öffnen und Text markieren.

## Vollbild

Klicken Sie auf die Vollbild-Schaltfläche neben den Pfeilen, um den ganzen Bildschirm zu nutzen. Drücken Sie `Esc`, um das Vollbild zu verlassen.

## Beenden

Klicken Sie oben rechts auf das X oder drücken Sie `Esc`.

Die Präsentation zeigt die Seite so, wie sie beim Start war. Wenn jemand die Seite bearbeitet, während Sie präsentieren, sehen Sie die Änderungen beim nächsten Öffnen des Präsentationsmodus.
