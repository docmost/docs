# Kommentare

Mit Kommentaren besprechen Sie eine Seite, ohne ihren Inhalt zu ändern. Sie können markierten Text oder die ganze Seite kommentieren, in Threads antworten und einen Thread lösen, wenn die Diskussion abgeschlossen ist.

## Einen Kommentar hinzufügen {#add-a-comment}

So kommentieren Sie einen Teil einer Seite:

1. Markieren Sie den Text.
2. Klicken Sie in der eingeblendeten Symbolleiste auf **Kommentar**.
3. Schreiben Sie Ihren Kommentar und klicken Sie auf **Speichern** oder drücken Sie `Ctrl/Cmd + Enter`.

Der Text wird hervorgehoben und der Kommentar erscheint im Kommentarfeld. Sie können auch im Lesemodus kommentieren.

Um die ganze Seite zu kommentieren, öffnen Sie das Kommentarfeld und schreiben Sie unten in das Feld **Kommentar hinzufügen...**.

Kommentare unterstützen Formatierungen, Links, Emojis sowie @-Erwähnungen von Personen und Seiten.

## Kommentare finden {#find-comments}

Klicken Sie in der Seiten-Symbolleiste auf das Symbol **Kommentare**, um das Kommentarfeld zu öffnen. Auch ein Klick auf hervorgehobenen Text öffnet den zugehörigen Kommentar.

Das Kommentarfeld hat die Tabs **Offen** und **Gelöst**. Bei einem Kommentar zu markiertem Text klicken Sie im Kommentarfeld auf den zitierten Text, um zu dieser Stelle der Seite zu springen.

## Auf einen Kommentar antworten {#reply-to-a-comment}

Schreiben Sie in das Feld **Antworten...** unter einem Thread und klicken Sie auf **Speichern**. Alle Antworten erscheinen in einer Liste unter dem ersten Kommentar.

## Einen Thread lösen {#resolve-a-thread}

Wenn eine Diskussion abgeschlossen ist, klicken Sie oben im Thread auf das Häkchen. Der Thread wechselt in den Tab **Gelöst** und die Hervorhebung im Text verschwindet. Jeder, der die Seite kommentieren darf, kann einen Thread lösen.

Um einen Thread wieder zu öffnen, suchen Sie ihn im Tab **Gelöst** und klicken Sie erneut auf das Häkchen.

## Einen Kommentar bearbeiten, löschen oder teilen {#edit-delete-or-share-a-comment}

Öffnen Sie das Menü (`...`) des Kommentars:

- **Kommentar bearbeiten** ändert den Text. Sie können nur Ihre eigenen Kommentare bearbeiten.
- **Kommentar löschen** entfernt den Kommentar. Sie können Ihre eigenen Kommentare löschen, Bereichsadministratoren können jeden Kommentar löschen. Wenn Sie den ersten Kommentar eines Threads löschen, werden auch seine Antworten gelöscht. Gelöschte Kommentare lassen sich nicht wiederherstellen.
- **Link kopieren** kopiert einen Link, der die Seite mit dem Kommentar im Kommentarfeld öffnet.

## Wer kommentieren kann {#who-can-comment}

Wer eine Seite bearbeiten kann, kann sie auch kommentieren. Betrachter können nur kommentieren, wenn ein Bereichsadministrator unter **Bereichseinstellungen** > **Sicherheit** die Option **Zuschauern erlauben, Kommentare zu hinterlassen** aktiviert. Diese Einstellung ist in den Editionen Business und Enterprise verfügbar.

Auf öffentlich freigegebenen Seiten werden keine Kommentare angezeigt.

## Benachrichtigungen {#notifications}

Sie erhalten eine Benachrichtigung in der App und per E-Mail, wenn:

- jemand Sie in einem Kommentar @-erwähnt
- jemand eine Seite kommentiert, die Sie beobachten
- jemand in einem Thread antwortet, an dem Sie beteiligt sind
- jemand Ihren Kommentar löst

Wenn Sie eine Seite kommentieren, beobachten Sie sie automatisch. Personen, die Sie @-erwähnen, werden nur benachrichtigt, wenn sie die Seite ansehen können. Welche dieser E-Mails Sie erhalten, legen Sie unter [E-Mail-Benachrichtigungen](/user-guide/preferences#email-notifications) fest.
