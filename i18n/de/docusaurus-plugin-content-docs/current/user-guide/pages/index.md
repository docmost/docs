# Seiten

Seiten sind die zentralen Inhaltseinheiten in Docmost. Jede Seite befindet sich innerhalb eines Bereichs und unterstützt Rich-Text-Bearbeitung, verschachtelte Unterseiten, Kommentare, Versionsverlauf und mehr.

## Eine Seite erstellen

So erstellen Sie eine neue Seite:

1. Klicken Sie in der Seitenleiste auf **Neue Seite** oder klicken Sie auf das **+**-Symbol neben der Überschrift **Seiten**.
2. Eine neue unbenannte Seite wird im Editor geöffnet.
3. Klicken Sie auf den Titelbereich, um Ihrer Seite einen Namen zu geben.
4. Beginnen Sie im Textbereich zu schreiben. Geben Sie `/` ein, um auf die Slash-Befehle zuzugreifen.

### Eine Unterseite erstellen

Seiten können verschachtelt werden, um eine Hierarchie zu erstellen. So erstellen Sie eine Unterseite:

1. Bewegen Sie den Mauszeiger über eine Seite in der Seitenleiste, um ein **+**-Symbol anzuzeigen.
2. Klicken Sie auf das **+**-Symbol, um eine untergeordnete Seite unter der ausgewählten Seite zu erstellen.

Sie können Seiten in der Seitenleiste auch per Drag-and-drop neu anordnen oder unter anderen Seiten verschachteln.

## Seiten-Symbolleiste

Oben auf jeder Seite finden Sie:

- **Bearbeiten / Lesen**-Umschalter – Wechseln Sie zwischen dem Bearbeitungs- und dem schreibgeschützten Modus.
- **Teilen** – Verwalten Sie die Einstellungen für die öffentliche Freigabe der Seite (sofern auf Arbeitsbereichsebene aktiviert).
- **Kommentare** – Öffnen Sie das Kommentarfeld, um Kommentare anzuzeigen, hinzuzufügen oder aufzulösen.
- **Inhaltsverzeichnis** – Öffnen Sie die Seitenleiste mit dem Inhaltsverzeichnis, das automatisch aus den Überschriften generiert wird.
- **Seitenmenü (...)** – Greifen Sie auf zusätzliche Seitenaktionen zu.

## Seitenmenü

Klicken Sie auf das **Drei-Punkte-Menü (...)** oben rechts auf einer Seite, um auf Folgendes zuzugreifen:

| Aktion | Beschreibung |
|--------|-------------|
| **Link kopieren** | Kopiert die Seiten-URL in die Zwischenablage |
| **Als Markdown kopieren** | Kopiert den Seiteninhalt als Markdown-Text |
| **Volle Breite** | Schaltet das Layout mit voller Breite für die Seite um |
| **Seitenverlauf** | Zeigt frühere Versionen der Seite an und stellt sie wieder her |
| **Verschieben** | Verschiebt die Seite und alle ihre Unterseiten in einen anderen Bereich |
| **Exportieren** | Exportiert die Seite im Markdown- oder HTML-Format |
| **PDF drucken** | Erzeugt eine PDF-Version der Seite |
| **In den Papierkorb verschieben** | Löscht die Seite, indem sie in den Papierkorb verschoben wird |

In der Fußzeile des Menüs werden außerdem die **Wortanzahl**, der **Name des Erstellers** und das **Erstellungsdatum** angezeigt.

## Seitenmenü in der Seitenleiste

Sie können auch mit der rechten Maustaste auf eine Seite in der Seitenleiste klicken oder den Mauszeiger darüber bewegen und auf das **Drei-Punkte-Menü (...)** klicken, um auf Schnellaktionen zuzugreifen:

| Aktion | Beschreibung |
|--------|-------------|
| **Link kopieren** | Kopiert die Seiten-URL in die Zwischenablage |
| **Seite exportieren** | Exportiert die Seite im Markdown- oder HTML-Format |
| **Duplizieren** | Erstellt eine Kopie der Seite an ihrer aktuellen Position innerhalb desselben Bereichs |
| **Verschieben** | Verschiebt die Seite und alle ihre Unterseiten in einen anderen Bereich |
| **In Bereich kopieren** | Kopiert die Seite und alle ihre Unterseiten in einen anderen Bereich, wobei das Original an seinem Platz erhalten bleibt |
| **In den Papierkorb verschieben** | Löscht die Seite, indem sie in den Papierkorb verschoben wird |

## Kommentare

Docmost unterstützt Inline-Kommentare zu Seiteninhalten. So fügen Sie einen Kommentar hinzu:

1. Markieren Sie den Text, den Sie kommentieren möchten.
2. Klicken Sie auf das **Kommentarsymbol** in der schwebenden Symbolleiste.
3. Geben Sie Ihren Kommentar ein und senden Sie ihn ab.

Kommentare werden im Kommentarfeld auf der rechten Seite der Seite angezeigt. Das Feld hat zwei Registerkarten:

- **Offen** – Aktive Kommentare, die Aufmerksamkeit erfordern.
- **Aufgelöst** – Kommentare, die aufgelöst wurden.

## Seitenverlauf

Docmost speichert den Seitenverlauf automatisch, während Sie bearbeiten. Während der ersten 5 Minuten nach Erstellung einer Seite werden jede Minute Schnappschüsse gespeichert. Danach wird der Verlauf während einer Bearbeitungssitzung alle 5 Minuten gespeichert.

So greifen Sie auf den Seitenverlauf zu:

1. Öffnen Sie das **Seitenmenü (...)**.
2. Klicken Sie auf **Seitenverlauf**.
3. Durchsuchen Sie die Liste der gespeicherten Versionen auf der rechten Seite.
4. Wählen Sie eine Version aus, um eine **Diff-Hervorhebung** anzuzeigen, die die Änderungen gegenüber der aktuellen Version zeigt.
5. Klicken Sie auf **Wiederherstellen**, um die Seite auf eine frühere Version zurückzusetzen.

## Freigabe

Sie können einzelne Seiten öffentlich mit jedem teilen, auch mit Personen außerhalb Ihres Arbeitsbereichs.

So geben Sie eine Seite frei:

1. Öffnen Sie die Seite, die Sie freigeben möchten.
2. Klicken Sie auf die Schaltfläche **Teilen** oder das **Globussymbol** in der Seiten-Symbolleiste.
3. Aktivieren Sie die Freigabe, um einen öffentlichen Link zu generieren.

### Freigabeoptionen

- **Unterseiten einbeziehen** – Wenn aktiviert, sind alle untergeordneten Seiten unter der freigegebenen Seite ebenfalls öffentlich zugänglich.
- **Indexierung durch Suchmaschinen zulassen** – Wenn aktiviert, können Suchmaschinen die freigegebene Seite indexieren. Wenn deaktiviert, ist die Seite weiterhin über den Link zugänglich, wird aber in den Suchergebnissen ausgeblendet.

### Freigabesteuerung

Die öffentliche Freigabe kann auf zwei Ebenen gesteuert werden:

- **Arbeitsbereichsebene** – Administratoren können die öffentliche Freigabe für den gesamten Arbeitsbereich unter **Einstellungen > Allgemein** deaktivieren.
- **Bereichsebene** – Bereichsadministratoren können die öffentliche Freigabe für einzelne Bereiche unter **Bereichseinstellungen** deaktivieren.

Einstellungen auf Arbeitsbereichsebene haben Vorrang vor Einstellungen auf Bereichsebene. Wenn die öffentliche Freigabe auf einer der beiden Ebenen deaktiviert ist, werden alle zuvor freigegebenen Seiten innerhalb dieses Bereichs automatisch wieder privat gestellt.

### Freigegebene Seiten verwalten

So zeigen Sie alle öffentlich freigegebenen Seiten in Ihrem Arbeitsbereich an:

1. Gehen Sie zu **Einstellungen > Öffentliche Freigabe**.
2. Durchsuchen Sie die Liste aller aktuell freigegebenen Seiten.

## Export

Einzelne Seiten können in den folgenden Formaten exportiert werden:

- **Markdown** – Exportiert die Seite als `.md`-Datei.
- **HTML** – Exportiert die Seite als `.html`-Datei.

Die Exportoptionen umfassen:

- **Unterseiten einbeziehen** – Exportiert die Seite zusammen mit allen ihren untergeordneten Seiten.
- **Anhänge einbeziehen** – Bündelt angehängte Dateien in den Export.

Exporte mehrerer Seiten werden als ZIP-Datei mit einer Ordnerstruktur verpackt, die der Seitenhierarchie entspricht.

So exportieren Sie eine Seite:

1. Öffnen Sie das **Seitenmenü (...)**.
2. Klicken Sie auf **Exportieren**.
3. Wählen Sie das Exportformat und die Optionen aus.
4. Klicken Sie auf **Exportieren**, um den Download zu starten.

## Seiten verschieben

Sie können eine Seite in einen anderen Bereich verschieben oder ihre Position in der Hierarchie ändern:

1. Öffnen Sie das **Seitenmenü (...)** und klicken Sie auf **Verschieben**, oder
2. Ziehen Sie die Seite per Drag-and-drop in der Seitenleiste, um sie neu anzuordnen oder zu verschachteln.

## Seiten löschen

So löschen Sie eine Seite:

1. Öffnen Sie das **Seitenmenü (...)**.
2. Klicken Sie auf **In den Papierkorb verschieben**.

Gelöschte Seiten werden in den Papierkorb verschoben und können von dort wiederhergestellt oder endgültig gelöscht werden.

## Papierkorb anzeigen

So zeigen Sie den Papierkorb an:

1. Navigieren Sie zu dem Bereich, in dem die Seite(n) gelöscht wurde(n).
2. Öffnen Sie das **Seitenmenü (...)**.
3. Klicken Sie auf **Papierkorb**
4. Von hier aus können Sie den Inhalt der Seite(n) anzeigen, indem Sie auf den Titel klicken

## Seite(n) wiederherstellen

So zeigen Sie den Papierkorb an:

1. Navigieren Sie zu dem Bereich, in dem die Seite(n) gelöscht wurde(n).
2. Öffnen Sie das **Seitenmenü (...)**.
3. Klicken Sie auf **Papierkorb**.
4. Klicken Sie auf das **Seitenmenü (...)** und wählen Sie Wiederherstellen.
5. Klicken Sie auf **Wiederherstellen**.
6. Fertig
