# Bereiche

Docmost-**Bereiche** sind dedizierte, organisierte Areale innerhalb Ihres Arbeitsbereichs, die Dokumente, Berechtigungen und Mitarbeiter nach Projekt, Team oder Zweck gruppieren.

Bereiche fungieren als Ordner der obersten Ebene. Innerhalb eines Bereichs können Sie:
- Seiten zwischen Bereichen verschieben oder kopieren
- Verschachtelte Seitenhierarchien erstellen
- Seiten in der Seitenleiste per Drag-and-Drop verschieben
- Seiten importieren oder exportieren

### Einen Bereich erstellen
So erstellen Sie einen neuen Bereich:

1. Gehen Sie zu **Einstellungen > Bereiche**.
2. Klicken Sie oben rechts auf die Schaltfläche **Bereich erstellen**.
3. Im Popup:
    - Geben Sie einen **Bereichsname** ein (z. B. `Engineering`).
    - Wählen Sie einen benutzerdefinierten **Bereichs-Slug**.
    - Fügen Sie eine optionale **Beschreibung** hinzu.
4. Klicken Sie auf **Erstellen**, um den Vorgang abzuschließen.
5. Sie werden zu dem neu erstellten Bereich weitergeleitet.

> Als Ersteller werden Sie zum **Bereichsadministrator** mit **Vollzugriff**-Berechtigungen.

### Mitglieder zu einem Bereich hinzufügen

So fügen Sie Mitglieder zu einem Bereich hinzu:

1. Klicken Sie in der Seitenleiste auf **Bereichseinstellungen** für den Bereich, den Sie verwalten möchten.
2. Gehen Sie im Popup zum Tab **Mitglieder**.
3. Klicken Sie auf **Bereichsmitglieder hinzufügen**.
4. Suchen Sie nach einzelnen Arbeitsbereichsmitgliedern oder Gruppen.
5. Wählen Sie eine Rolle aus und klicken Sie auf **Hinzufügen**.

Die verfügbaren Bereichsrollen sind:
- **Vollzugriff:** Volle Kontrolle über Einstellungen, Berechtigungen und Seiten.
- **Bearbeiten:** Kann Seiten innerhalb des Bereichs erstellen und ändern.
- **Betrachter:** Kann Seiten ansehen, aber nicht bearbeiten.

### Ein Mitglied aus einem Bereich entfernen

So entfernen Sie jemanden aus einer Gruppe:

1. Gehen Sie zu **Einstellungen > Gruppen**.
2. Wählen Sie die Gruppe aus.
3. Suchen Sie das Mitglied, das Sie entfernen möchten.
4. Klicken Sie auf die **drei Punkte (⋯)** neben dem Namen.
5. Wählen Sie **Bereichsmitglied entfernen**.
6. Bestätigen Sie die Aktion.


### Einen Bereich bearbeiten

So aktualisieren Sie die Details eines Bereichs:

1. Gehen Sie zu **Einstellungen > Bereiche**.
2. Wählen Sie den Bereich aus.
3. Wechseln Sie im Popup zum Tab **Einstellungen**.
4. Bearbeiten Sie den **Namen**, den **Slug** oder die **Beschreibung**.
5. Klicken Sie auf **Speichern**, um die Änderungen zu übernehmen.

### Einen Bereich exportieren

Sie können Seiten und Anhänge innerhalb eines Bereichs für die Sicherung, Migration oder Offline-Nutzung exportieren. Docmost bietet sowohl Markdown- als auch HTML-Exportformate.

  <p align="center">
<img src="/docs/img/space-settings.png" width="500"/>
</p>

So exportieren Sie einen Bereich:

1. Navigieren Sie zu den **Bereichseinstellungen**.

2. Wählen Sie innerhalb der **Bereichseinstellungen** oben den Tab **Einstellungen** aus.

3. Klicken Sie auf die Schaltfläche **Exportieren**, um den Exportvorgang zu starten.

  <p align="center">
<img src="/docs/img/export-space.png" width="500"/>
</p>

4. Im Export-Dialog:
   - Wählen Sie Ihr gewünschtes Exportformat: **Markdown** oder **HTML**.
   - Aktivieren Sie die Option **Anhänge einbeziehen**, wenn Sie angehängte Dateien zusammen mit Ihren Inhalten exportieren möchten.

5. Klicken Sie auf die Schaltfläche **Exportieren**, um den Download zu starten.

Die exportierten Inhalte werden in einer ZIP-Datei gebündelt und automatisch auf Ihr Gerät heruntergeladen. Anschließend können Sie sie nach Ihren Bedürfnissen extrahieren und verwenden.

### Einen Bereich löschen

So löschen Sie einen Bereich dauerhaft:

1. Öffnen Sie die **Einstellungen** des Bereichs.
2. Wechseln Sie zum Tab **Einstellungen**.
3. Klicken Sie auf die Schaltfläche **Löschen**.
4. Im Bestätigungsdialog:
   - Geben Sie zur Bestätigung den Bereichsnamen ein.
   - Klicken Sie auf **Bestätigen**.

> ⚠️ Diese Aktion ist unwiderruflich. Der Bereich und sein gesamter Inhalt werden dauerhaft gelöscht.
