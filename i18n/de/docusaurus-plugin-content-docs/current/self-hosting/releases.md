# Versionen

Docmost wird als Docker-Image bereitgestellt. Die Versionshinweise werden auf GitHub veröffentlicht. Lesen Sie die Versionshinweise, bevor Sie Ihre Installation aktualisieren.

- [GitHub Releases](https://github.com/docmost/docmost/releases) — Versionshinweise, Änderungen und Hinweise zur Aktualisierung.
- [Docker Hub](https://hub.docker.com/r/docmost/docmost) — Docker-Images und verfügbare Tags.

Folgen Sie zum Aktualisieren Ihrer Installation der [Aktualisierungsanleitung](/installation#aktualisierung).
